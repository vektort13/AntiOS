# Security audit note

A detailed internal security audit was performed during the AntiOS v2 alpha development cycle.

The public repository no longer publishes the audit's exploit-relevant findings, trust-boundary diagrams, failure sequences or remediation internals because those details materially simplify reconnaissance against unfinished protection paths.

Public result:

- security-sensitive findings were reviewed and fixes were integrated into subsequent alpha work;
- fail-safe behavior, update/repair validation, recovery integrity and privilege boundaries received additional hardening;
- AntiOS remains pre-release software and should not be treated as independently certified.

Researchers should report vulnerabilities privately through [../SECURITY.md](../SECURITY.md).
