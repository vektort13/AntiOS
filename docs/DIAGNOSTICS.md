# Diagnostics

AntiOS diagnostics help distinguish healthy, degraded and incomplete states.

They can include application version, operating-system information, protection-provider status and local runtime events relevant to troubleshooting.

Support exports are created only when requested. Review them before sharing because they can contain local paths, hashes and machine-specific system information.

Diagnostics should not include quarantined malware contents or raw process-memory data during normal support export.
