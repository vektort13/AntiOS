# Diagnostics

AntiOS provides local diagnostics for protection and runtime health.

## Public behavior

- shows human-readable protection/runtime events;
- helps distinguish healthy, degraded and incomplete states;
- can create privacy-conscious support material;
- does not intentionally include quarantined malware samples in normal support exports.

## Security boundary

Public documentation does not publish internal event schemas, file locations, rotation limits, component identifiers, redaction rules or support-export assembly details. Those internals are intentionally kept out of public-facing documentation.
