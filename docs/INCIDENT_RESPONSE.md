# Incident response

AntiOS provides conservative, user-driven response actions for local security findings.

## Public behavior

- rescan suspicious content;
- open relevant locations for review;
- export a local report;
- isolate content only when the product has sufficient trusted evidence and the action is explicitly authorized.

AntiOS does not publish internal response sequencing, revalidation order, rollback mechanics, privilege handoff or quarantine transaction details in public documentation.
