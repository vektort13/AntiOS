# Storage Intelligence

Storage Intelligence provides local, bounded assistance for understanding cleanup candidates and storage trends.

## Public behavior

- identifies potential duplicate or cleanup candidates;
- can keep limited aggregate history when the user enables that capability;
- can remember user cleanup preferences;
- can verify selected backup material before a recovery test;
- never treats an estimate as permission to delete;
- destructive actions require explicit confirmation;
- incomplete scans do not authorize destructive cleanup.

## Privacy and limitations

Storage Intelligence is not a continuous surveillance/indexing service, not a backup replacement and not a guarantee that a candidate is safe to remove.

Public documentation intentionally omits database names/paths, retention counts, exact trend formulas, hashing sequence, proof-test limits, idle/power thresholds and other implementation parameters.
