# Linux companion

Linux support is supplemental and intentionally smaller than Windows support.

The published x86_64 archive targets glibc 2.39 or newer, for example Ubuntu 24.04 LTS or a compatible distribution. The GUI requires X11 or XWayland. The Python package can also be used for CLI-oriented scenarios.

## Available scope

Linux builds can provide on-demand AntiOS scanning, selected diagnostics, storage tools, coexistence status and the optional GUI. Resident behavior is more limited than on Windows and depends on the supported local environment.

AntiOS does not take ownership of Kaspersky or Dr.Web policy, stop their services or add exclusions.

Musl-based distributions and older glibc releases are not supported by the published portable binary unless a release explicitly says otherwise.
