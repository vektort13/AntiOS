# AntiOS

[English](README.md) · **Русский** · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [Suomi](README.fi.md) · [Polski](README.pl.md) · [Монгол](README.mn.md)

AntiOS — toolkit для endpoint-security и обслуживания системы с основной поддержкой Windows и дополнительным Linux-компаньоном.

> **Текущая версия исходников:** `3.0.2a1`<br>
> **Последний опубликованный релиз:** [Релизы на GitHub](https://github.com/Dargon777/AntiOS/releases)<br>
> **Статус:** предварительная версия

## Что умеет AntiOS

- проверять файлы и папки по запросу;
- предоставлять опциональную резидентную защиту;
- помещать обнаружения в карантин и явно восстанавливать их;
- работать рядом с Microsoft Defender и поддерживаемыми продуктами Kaspersky / Dr.Web;
- показывать диагностику безопасности, состояния Windows и системы;
- выполнять Storage Cleanup и Storage Intelligence;
- использовать ограниченные средства восстановления и проверки целостности файлов;
- показывать локальное состояние защиты и инцидентов;
- распространяться как Windows-установщик, portable-сборка и Python-пакет;
- работать в дополнительном режиме-компаньоне на Linux x86_64.

AntiOS задуман как дополнительный защитный слой и не должен незаметно отключать или перенастраивать другой установленный антивирус.

## Поддерживаемые платформы

| Платформа | Статус | Примечание |
| --- | --- | --- |
| Windows 10 22H2 x64 | Основная поддержка | Установщик и portable |
| Windows 11 x64 | Основная поддержка | Установщик и portable |
| Linux x86_64 | Дополнительный companion-режим | Portable-сборка требует glibc 2.39+; для GUI нужен X11 или XWayland |
| Python 3.11+ | Исходники / пакет | CLI и сценарии разработки |

Linux-поддержка намеренно уже Windows-поддержки и не заявляет нативную интеграцию со всеми пакетными менеджерами и системными сервисами дистрибутивов.

## Антивирус и совместная работа

AntiOS предоставляет собственное сканирование и опциональную резидентную защиту, не забирая управление настройками поддерживаемого стороннего антивируса.

На Windows поддерживается совместная работа с Microsoft Defender и отдельными продуктами Kaspersky / Dr.Web. Linux companion-режим также может отображать состояние поддерживаемой сторонней защиты, когда это доступно.

AntiOS **не заявляет** сертифицированный статус основного антивируса Windows, ELAM/PPL, полную boot-time защиту или идеальный перехват угроз до запуска.

## Помощник защиты

В центре антивируса нажмите **Помощник**:

- **Самопроверка** проверяет движок безопасными образцами и выполняет пробное сохранение и извлечение копии.
- **Снимки файлов** сравнивают два архива и позволяют извлечь прежние версии изменённых или отсутствующих файлов.
- **Объяснения событий** показывают причины тревоги и следующие действия на основе локального журнала.

Для автоматизированной проверки доступна команда `antios self-check --json`. Успешная самопроверка относится к текущему состоянию; она не гарантирует обнаружение всех угроз.

## Хранилище и восстановление

Storage Cleanup и Storage Intelligence помогают искать кандидатов на очистку и анализировать использование диска, при этом разрушительные действия требуют явного подтверждения.

Функции восстановления — это ограниченные средства резервирования и проверки целостности. Они не являются полным rollback системы и не гарантируют отсутствие вредоносного содержимого в восстановленном файле.

## Установка

Для обычного использования на Windows устанавливайте последний `AntiOS-Setup.exe` из Releases.

Portable-архив Windows подходит для сценариев без установки. На совместимых Linux-системах можно использовать опубликованную x86_64 сборку. Python-пакеты в основном предназначены для разработки и пакетных сценариев.
