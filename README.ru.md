# AntiOS

[English](README.md) · **Русский** · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [Suomi](README.fi.md) · [Polski](README.pl.md) · [Монгол](README.mn.md)

AntiOS — предварительная версия проекта для защиты конечной системы и обслуживания Windows. Для Linux есть отдельный companion-режим с более узким набором возможностей.

**Версия ветки разработки:** 3.0.2a1  
**Релизы:** https://github.com/Dargon777/AntiOS/releases

## Что сейчас есть

AntiOS умеет:

- проверять файлы и папки собственным локальным движком AntiOS Engine;
- запускать опциональный Resident Guard;
- помещать подтверждённые находки в карантин и явно восстанавливать их;
- сохранять отчёты о проверке, показывать неполное покрытие и повторно воспроизводить решение из отчёта;
- показывать состояние Windows, защиты и системы;
- собирать ограниченные данные о процессах, автозапуске, памяти процессов, загруженных драйверах и boot/security posture;
- связывать сигналы в контекст риска и инцидентов без автоматического удаления по одной слабой эвристике;
- выполнять Storage Cleanup, Storage Intelligence и ограниченное восстановление файлов;
- работать рядом с Microsoft Defender и поддерживаемыми установками Kaspersky / Dr.Web;
- собираться как Windows Setup, portable-пакет и дополнительная Linux x86_64 версия.

Проект всё ещё находится в разработке. AntiOS **не заявляет** сертификацию как основной антивирус Windows, ELAM/PPL, полную защиту до загрузки ОС или идеальный перехват угроз до запуска.

## Платформы

| Платформа | Статус |
| --- | --- |
| Windows 10 22H2 x64 | Поддерживаемая цель |
| Windows 11 x64 | Поддерживаемая цель |
| Linux x86_64 | Дополнительный companion |
| Python 3.11+ | Разработка / пакетная установка |

Linux-поддержка заметно уже Windows-поддержки.

## Загрузка

Используйте последний опубликованный релиз на GitHub. В нём могут быть Windows Setup и portable-сборка, Linux x86_64 архив и Python-пакеты.

Некоторые предварительные Windows-сборки публикуются без цифровой подписи. Перед установкой смотрите release notes и приложенные SHA-256.

## Разработка

Проект развивается публично, но детали уязвимостей и работающие способы обхода защиты не нужно публиковать в issue или PR — для этого есть приватный security-reporting.

Обычный рабочий процесс репозитория специально остаётся простым: одна задача — одна ветка — один PR, несколько осмысленных коммитов, CI и squash merge.
