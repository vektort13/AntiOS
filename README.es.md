## Qué comprueba AntiOS

- Microsoft Defender y protección en tiempo real;
- BitLocker/cifrado del dispositivo;
- Arranque seguro y TPM;
- espacio libre en la unidad del sistema;
- reinicios pendientes;
- aplicaciones de inicio;
- versión y compilación de Windows;
- arquitectura, procesador y tiempo de actividad.

La interfaz detecta automáticamente Windows en español y también permite cambiar manualmente entre **English / Русский / Español / 简体中文 / Suomi / Polski / Монгол**.

El árbol de desarrollo actual incluye análisis independiente de archivos bajo demanda, protección residente opcional, cuarentena y restauración, diagnóstico de seguridad y herramientas de almacenamiento. AntiOS procesa los datos localmente de forma predeterminada y no activa telemetría automática. Consulte [README.md](README.md) para ver las capacidades y limitaciones actuales completas.
