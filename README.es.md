# AntiOS

[English](README.md) · [Русский](README.ru.md) · **Español** · [简体中文](README.zh-CN.md) · [Suomi](README.fi.md) · [Polski](README.pl.md) · [Монгол](README.mn.md)

AntiOS es un proyecto de seguridad de endpoint y mantenimiento para Windows, con un modo complementario más limitado para Linux.

**Versión de desarrollo:** 3.0.2a1  
**Descargas:** https://github.com/Dargon777/AntiOS/releases

Incluye análisis local de archivos y carpetas, Resident Guard opcional, cuarentena y restauración, diagnósticos de Windows, sensores de seguridad del sistema y herramientas de almacenamiento y recuperación limitada.

AntiOS sigue siendo software preliminar. No afirma ser un antivirus principal certificado para Windows ni ofrecer bloqueo perfecto antes de la ejecución.

Plataformas principales: Windows 10 22H2 x64 y Windows 11 x64. Linux x86_64 se ofrece como companion suplementario.
