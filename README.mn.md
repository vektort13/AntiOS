## AntiOS юу шалгадаг вэ

- Microsoft Defender ба бодит цагийн хамгаалалт;
- BitLocker/төхөөрөмжийн шифрлэл;
- Secure Boot ба TPM;
- системийн дискний сул зай;
- restart хүлээгдэж байгаа эсэх;
- түгээмэл startup програмууд;
- Windows-ийн хувилбар ба build;
- архитектур, процессор ба ажилласан хугацаа.

Монгол locale автоматаар танигдана. Хэлийг мөн гараар сольж болно: **English / Русский / Español / 简体中文 / Suomi / Polski / Монгол**.

Одоогийн хөгжүүлэлтийн хувилбар нь бие даасан файл скан, сонголттой байнгын хамгаалалт, хорио ба сэргээх, аюулгүй байдал ба системийн оношлогоо, хадгалалтын хэрэгслүүдийг агуулна. AntiOS өгөгдлийг анхдагчаар локал боловсруулдаг бөгөөд автомат телеметрийг идэвхжүүлдэггүй. Одоогийн бүх боломж ба хязгаарлалтыг [README.md](README.md)-ээс үзнэ үү.
