# AntiOS

[English](README.md) · [Русский](README.ru.md) · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [Suomi](README.fi.md) · [Polski](README.pl.md) · **Монгол**

AntiOS нь Windows-д зориулсан endpoint security болон системийн засвар үйлчилгээний төсөл бөгөөд Linux-д илүү хязгаарлагдмал companion горимтой.

**Хөгжүүлэлтийн хувилбар:** 3.0.2a1  
**Releases:** https://github.com/Dargon777/AntiOS/releases

Одоогийн боломжуудад локал файл/хавтас скан, сонголттой Resident Guard, хорио ба сэргээх, Windows оношлогоо, системийн аюулгүй байдлын сенсорууд, хадгалалт болон хязгаарлагдмал файл сэргээх хэрэгслүүд орно.

AntiOS нь урьдчилсан хувилбар хэвээр. Windows-ийн сертификаттай үндсэн антивирус эсвэл ажиллахаас өмнөх төгс хаалт гэж мэдэгддэггүй.

Үндсэн зорилтот системүүд: Windows 10 22H2 x64 ба Windows 11 x64. Linux x86_64 нь нэмэлт companion хувилбар.
